# ☕ Toleransi Coffee Sales Dashboard

Interactive sales dashboard project created using Microsoft Excel.

## 📊 Project Overview
This dashboard analyzes coffee shop sales performance during March 2026.

The dashboard helps monitor:
- Revenue performance
- Best-selling products
- Sales trends
- Product category contribution
- Customer purchasing behavior

---

## 🔍 Key Insights
- Americano became the best-selling product
- Espresso-based beverages generated the highest revenue
- Sales peaked during evening hours (18:00–20:00)
- Customer transactions remained stable throughout the week

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Table
- Pivot Chart
- Data Visualization
